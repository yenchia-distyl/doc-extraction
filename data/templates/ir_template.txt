The following is the Intermediate Representation Template format, referred to as the ir_template.

If the value is surrounded by enclosed angle brackets you MUST ignore that field.

This is is the python definition of the object. All extractions should be as a JSON that can be instantiated by this class.

class IRDataPoint:
    # The name of the field
    data_point_name: str
    # Define the field
    description: str
    related_routine_steps: List[str]
    # Describe what the field is used for
    rationale: str
    # Give a process to extract the field
    extraction_instructions: str
    # Concrete examples of the field
    examples: List[str]
